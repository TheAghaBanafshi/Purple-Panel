## پنل ساخت کانفیگ - Purple Panel
با این پروژه شما مستونید با یک داشبورد مدیریتی کانفیگ پرسرعت V2ray بسازید

## مراحل قدم به قدم آوردن پنل 
 .
 ## قدم اول
 در سایت [github](https://github.com) با ایمیل خود ثبت نام کنید.
 ## قدم دوم 
 در سایت [railway.app](https://railway.app) با اکانت گیت هاب که ساختید ثبت نام کنید.
 ## قدم سوم 
 در صفحه اصلی سایت [railway.app](https://railway.app) روی گزینه ی Deploy کلیک کنید.
 و بعدش گزینه ی Github Repository کلیک کنید و بعد روی Install Github App بزنید.
 و یک پنجره باز میشه (اگر رو پیسی باشید) داخل اون پنجره دسترسی All Repository رو بدید و بعد روی Install & Auturise کلیک کنید بعد اینکه زدید دوباره وارد صفحه اصلی سایت [railway.app](https://railway.app) شوید و دوباره روی Deploy کلیک کنید و بعد رو Github Repository و بعد در کادر بالا لینک
